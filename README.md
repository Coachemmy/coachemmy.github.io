A professional bilingual portfolio website showcasing expertise in Artificial Intelligence, Machine Learning, Full-Stack Development, and Tech Consulting.

## 📌 Live Site
[View Portfolio](https://coachemmy.github.io/)

## ✨ Features

- **Bilingual Support** - English / 中文 with seamless language switching
- **3D Interactive UI** - Smooth animations, hover effects, and scroll-triggered reveals
- **Responsive Design** - Optimized for desktop, tablet, and mobile
- **Dark/Light Mode** - Toggle between themes for comfortable viewing
- **PDF Export** - One-click resume download
- **Contact Integration** - Direct email and social media links

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3 with 3D transforms, Flexbox, Grid
- **Interactivity:** Vanilla JavaScript
- **Icons:** Font Awesome 6.4
- **Fonts:** Inter, Noto Sans SC (Google Fonts)
- **Deployment:** GitHub Pages
